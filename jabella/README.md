# JABELLA Store

Sistema de inventario, ventas y dinero de JABELLA Store (Socopó, Venezuela).

- App: **https://app.mercantilyumana.com/jabella/**. En el iPhone: Safari → Compartir → **Agregar a inicio**.
- Base de datos: Supabase de Mercantil Yumana, aislada con prefijo `jab_`. Estructura en `supabase/migrations/`.
- Instrucciones para trabajar el código: `CLAUDE.md`.
