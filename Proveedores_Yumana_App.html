ℹ️ Cómo funciona

1. Almacenamiento local: Los datos viven en tu teléfono (IndexedDB).

2. Fotos: Cada factura puede tener una foto. Se comprimen automáticamente para no llenar el espacio.

4. Restaurar: "Importar Backup" desde aquí, selecciona el archivo .json y listo.

5. Espacio: El sistema avisa si te estás quedando sin espacio.
