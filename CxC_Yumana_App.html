ℹ️ Cómo funciona

1. Almacenamiento local: Tus datos se guardan en tu teléfono, en este navegador.

2. Backup obligatorio: Exporta el backup al menos cada semana y mándalo a tu WhatsApp o iCloud. Si pierdes el teléfono o limpias datos del navegador, sin backup pierdes todo.

3. Restaurar: Si pasa algo, importa el backup desde el menú.

4. Fotos: Se comprimen automáticamente para ahorrar espacio.

¿Importar backup?

Se reemplazará TODA la información actual con la del archivo. Esta acción no se puede deshacer.
